# JavaScript Learning

> 📚 **Learning repo.** Vanilla JavaScript practice, from small HTML/CSS/JS projects to DOM, state and async fundamentals. Merged from two earlier repos with their full commit history.

## 01 · Mini projects

Small HTML, CSS and JavaScript projects, each built around one feature or idea.

Age generator · Book list · Calculator · Music player · Notifications · Number counter · Password generator · Product filter · QR code generator · Quiz app · Stopwatch · To-do list · Form validation · Weather app · Slider

See the [01-mini-projects](./01-mini-projects) folder.

## 02 · JavaScript practice

Exercises grouped by the concept they practise.

| Folder | Concept | Exercises |
|---|---|---|
| [DOM_Events](./02-js-practice/DOM_Events) | Selecting elements, event listeners | Character counter, dark mode, highlight nav, show/hide section |
| [Functions_State](./02-js-practice/Functions_State) | Functions, closures, UI state | FAQ accordion, image carousel, Pomodoro timer |
| [Logic_Data](./02-js-practice/Logic_Data) | Arrays, objects, filtering | Filterable projects, quiz, tip calculator, todo list |
| [APIs_Async](./02-js-practice/APIs_Async) | `fetch`, `async/await`, error handling | Weather app |

## Running a project

No build step. Open the project's `.html` file in a browser, or use the VS Code Live Server extension.
